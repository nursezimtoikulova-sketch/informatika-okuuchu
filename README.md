# Окуучулардын сайты — Информатика «НурАиша»
Окуучу логин жана пароль менен катталат (email жок), мугалим берген код менен сабак ачат, флешкарта, оюн жана практика аткарат. Жыйынтыктар сакталат.

## GitHub + Vercel
1. Бул папканын ичиндегилерди өзүнчө GitHub репозиторийге жүктөңүз (мис. `informatika-okuuchu`).
2. Vercel → Add New → Project → ошол репозиторийди тандаңыз (Framework: Other) → Deploy.
3. Vercel → Storage → Create → **Upstash for Redis** (акысыз) → бул долбоорго туташтырыңыз.
4. Settings → Environment Variables: `TEACHER_PIN` (мугалимдин PIN-коду) жана `SECRET` (каалагандай узун сөз). Анан Redeploy.

Сабактын коддору эки сайтта бирдей болушу үчүн `app.js` файлын эки сайтта тең бирдей кармаңыз.
